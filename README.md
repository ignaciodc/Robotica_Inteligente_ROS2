## 🧪 Requisitos

- Ubuntu 20.04 / 22.04
- ROS 2 (Humble / Foxy según el capítulo)
- Python 3.8+
- colcon
- Gazebo / RViz
- Docker (opcional pero recomendado)

Los requisitos específicos se indican en cada subcarpeta.
