# Capítulo 6 – Visión por computador con ROS2 y OpenCV

La percepción visual constituye uno de los pilares fundamentales de la robótica móvil moderna. Mientras que sensores como el LIDAR permiten una representación geométrica precisa del entorno, la visión por computador aporta información semántica rica, imprescindible para tareas avanzadas como la detección de objetos, el reconocimiento de señales, la interacción con personas o la comprensión del contexto operativo.
