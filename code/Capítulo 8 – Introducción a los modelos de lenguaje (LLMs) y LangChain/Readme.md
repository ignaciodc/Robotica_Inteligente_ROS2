# Capítulo 8 – Introducción a los modelos de lenguaje (LLMs) y LangChain

En los últimos años, los modelos de lenguaje de gran tamaño (Large Language Models, LLMs) han transformado de manera radical el campo del procesamiento del lenguaje natural (Natural Language Processing, NLP). Estos modelos han demostrado capacidades avanzadas para comprender, generar y razonar sobre lenguaje humano, permitiendo nuevas formas de interacción entre sistemas informáticos y personas. Tecnologías como asistentes conversacionales, sistemas de recomendación semántica, análisis automático de texto o generación de código son hoy posibles gracias a la madurez alcanzada por los LLMs.
