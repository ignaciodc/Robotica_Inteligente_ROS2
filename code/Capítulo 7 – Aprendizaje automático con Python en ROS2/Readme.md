# Capítulo 7 – Aprendizaje automático con Python en ROS2

El aprendizaje automático (Machine Learning, ML) se ha consolidado como una herramienta esencial para dotar a los robots de capacidades cognitivas avanzadas. La integración de modelos preentrenados y la ejecución de inferencia en tiempo real permite que un robot perciba, interprete y reaccione ante su entorno de manera autónoma y eficiente. En este capítulo del libro, se aborda el uso de frameworks como PyTorch y TensorFlow dentro del ecosistema ROS 2, así como estrategias para ejecutar inferencia en tiempo real sobre flujos de datos provenientes de sensores, principalmente cámaras.
