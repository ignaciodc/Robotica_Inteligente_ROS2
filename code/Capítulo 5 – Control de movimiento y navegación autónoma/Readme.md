# Capítulo 5 – Control de movimiento y navegación autónoma

El control de movimiento y la navegación autónoma constituyen uno de los pilares fundamentales de la robótica móvil moderna. En el ecosistema ROS 2, este conjunto de capacidades se articula principalmente a través de «Nav2» (_Navigation 2_), el _framework_ oficial de navegación para ROS 2. Nav2 representa la evolución natural del conocido _navigation stack_ de ROS1. El código de este Capítulo se presenta a continuación:
